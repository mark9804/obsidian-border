# obsidian-theme-border-arco

> [!WARNING]
> **This theme will only work on Obsidian 1.5.8 and above due to intensive use of CSS nesting techniques.**

A rework of [Obsidian Border Theme](https://github.com/Akifyss/obsidian-border) using [Arco Design Guidelines](https://arco.design/).
